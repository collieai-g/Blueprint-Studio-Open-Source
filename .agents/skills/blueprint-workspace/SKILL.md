# Blueprint workspace

For installation or connection, read `INSTALL.md` at the repository root and follow its detection, preservation and verification steps. Use the user's selected deployment target; a temporary coding environment is not automatically their permanent company server.

For company work, read `docs/CODEX-WORKSPACE.md` before the first task, then call `blueprint_workspace_info`. If available through MCP, that tool also returns the operating instructions. Use the actual Blueprint tools, current company facts and permissions. Keep conversation in Codex and persist useful answers/results in Blueprint. Do not substitute imagined records or simulated worker outcomes.

When the MCP server has just been configured, verify discovery in the actual Codex client. A new/refreshing Codex conversation may be needed. The current conversation's existing tool list is not proof of a new connection.
