      使用說明

      工作與資料

      「工作」保存項目、待辦與每日紀錄；「資料」整理文件、收藏、主題及封存內容。你可在左側向 Codex 說明要求，在右側核對保存結果。

      調整每頁版面

      按右上方「調整版面」，選擇顯示內容、修改標題或說明，再移動、調整大小或收合卡片。可將工作和 AI 卡片放到總覽。支援同步的後台會保存同一帳戶的版面，其他分頁和裝置會自動接收；編輯期間保留手上的修改，衝突時由你選擇。舊後台會明確顯示僅在本機保存。

      查看最新資料

      在工作台內保存後會更新相關內容；外部保存後，從上方「操作」選擇「更新資料」。閒置或切回視窗不會自動重建畫面。

      常用操作

      用 Ctrl／⌘ K 搜尋資料，按 Esc 關閉視窗。搜尋、更新資料、手動上載、收藏及匯入工作都在上方「操作」內。
