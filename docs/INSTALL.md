# Blueprint Studio Open Source｜完整安裝指南

**V2.6 新安裝先讀 [原生安裝與持續更新](NATIVE_LIFECYCLE.md)。** 必須完成完整備份下載、隔離還原、重啟保存及日後部署能力驗收。沒有平台偏好時，優先選原生本機／雲端；Sites 仍需另行適配及驗證。V2.6 新增獨立 Agent 工作台，沿用原有帳戶、公司資料與 AI 接駁流程。

[返回首頁及複製安裝指令](../README.md#貼給你的-ai開始安裝)

目標是由一段安裝指令開始，逐步建立你自己的藍圖工作台：打開**原版完整介面**、登入、保存工作，再次開啟仍能繼續使用。AI 應陪同完成整條路線，每次只交代目前一步及需要你操作的事項。

完整安裝包的入口是 [INSTALL_AI.txt](../INSTALL_AI.txt)。可直接把整段文字貼給 AI，或上載完整 ZIP 並請它讀取入口。工作台內置 [AI 接駁中心](CONNECT.md)：安裝 AI 必須帶到真實工具讀寫、右側顯示及第一項工作，不能停在網站可開啟。

## 先確定這次任務，才讀取進度

先沿用使用者已表明的選擇，不能只因找到舊站就自動改為更新。意圖不清楚才確認一次。

| 本次目標 | 使用方式 | 舊站怎樣處理 |
| --- | --- | --- |
| 第一次使用，或明確另外全新安裝 | 本安裝入口；新的私人記錄、資料、備份及服務 | 如有舊站，保留網址、登入、附件、資料與綁定，不改動也不自動匯入 |
| 保留資料更新原工作台 | [UPDATE_AI.txt](../UPDATE_AI.txt)；沿用原服務的進度 | 完成原資料完整備份後更新原站 |
| 要把舊資料搬到新後台 | 另行制定資料搬遷與核對流程 | 需驗證匯出、附件、身份及還原；不得冒稱已搬好 |

**另裝原生新站，不需要先完成舊 Sites 的 D1／R2 備份或封裝。** 這是因為新安裝不碰舊站，並非降低舊站更新或資料搬遷的要求。不要把原生 Python 程式部署到舊 Site，也不要重用原磁碟、資料路徑或 MCP 綁定。相同 GitHub／主機帳戶可沿用；新服務與儲存必須獨立，收費按既有授權處理。

選了全新安裝後，將舊任務標記「保留、未執行本次更新」，原私人進度留下。另開新的私人 `INSTALL_PROGRESS.md`，記錄新目標、預定資料位置及被保護的舊服務。若新安裝中途換對話，只接續這份新記錄；原候選、舊網址或另一個版本的測試不能成為新站已完成的證據。新站仍要驗證自己的完整備份、耐久副本、重啟保存、登入及 AI 寫入。

## 從新對話開始

1. 在 Codex 或具備相應工具的 AI 開新對話，貼上[首頁安裝指令](../README.md#貼給你的-ai開始安裝)。
2. AI 先讀本指南及 `AGENTS.md`，檢查已有工作台、程式、資料位置與可用工具，保留已有資料和修改。
3. **先選本機或雲端**。已有選擇就直接沿用，不重問。再提供工作室／公司名稱；個人使用可用自己的名字，行業、簡介及目標可稍後補。
4. AI 進入所選路線，完成目前步驟才繼續下一步。不要一次要求使用者自行研究所有供應商。

| 選擇 | 完整路線 | 完成後怎樣使用 |
| --- | --- | --- |
| **本機安裝** | 檢查自己的電腦 → 下載完整程式 → 私人資料及登入 → 啟動原版工作台 → 保存驗證 → AI 連接 | 在同一部電腦啟動服務、打開實際本機地址 |
| **雲端安裝** | 帳戶與完整原始碼 → 按需要接入 Codex 雲端 → 選正式部署方式 → 原版工作台及永久儲存 → 保存驗證 → AI 連接 | 開啟自己可登入的 HTTPS 工作台，可在支援的 ChatGPT 右側瀏覽器開啟 |

- [開始本機安裝：Windows／macOS／Linux](INSTALL_LOCAL.md)
- [開始雲端安裝：GitHub、Codex、正式部署及 Sites](INSTALL_CLOUD.md)

Codex 雲端是 AI 工作環境；其 Publish／Republish 完成後，繼續雲端指南的正式工作台部署。實際網站需有持續運行的服務、儲存及可登入網址。本機路線不要求建立 GitHub 帳戶或 Codex 雲端環境。

## AI 每一步怎樣帶領

安裝 AI 應先確認目前在哪部機器執行，以及能否讀檔、執行指令、存取 GitHub、部署或開啟瀏覽器。使用者的本機與遠端 Codex 工作區要分清楚；遠端 `127.0.0.1` 不代表使用者電腦，也不是對外網址。

有工具及授權就完成相應工作：檢查帳戶、準備完整程式、建立所需設定、測試、取得入口。遇到只有使用者才能完成的註冊、登入、驗證碼、平台授權、費用確認或 Publish 按鈕，提供**目前頁面入口、需要填的內容、成功後應看見甚麼**，完成後接續原步驟。沒有相關工具的普通聊天 AI 則提供當前一步的實際操作，不聲稱已執行。

帳戶可沿用已有帳戶；「建立私人程式倉庫」不代表需要再註冊 GitHub。密碼、金鑰在平台秘密設定或安全終端機輸入；不要要求貼到聊天。沿用已授權的操作和預算，新收費資源才核對未授權費用。

每次進度只需交代：

> 目前：雲端路線，完整程式已準備好。
>
> 需要你做：在環境設定選擇剛建立的私人倉庫。
>
> 接著：驗證環境，再進入正式工作台部署。

AI 工具接駁必須完成 [不同 AI 的 MCP 接駁指南](AI_CONNECTION.md)，分清外掛安裝、授權、工具載入及實際讀寫。不能把網站已打開當作 AI 已接通。

## 安裝必須沿用原版介面

正式工作台來源是 `library_web/`：`index.html`、`style.css`、`app.js`、`workdays.js`、`workspace.js`、`brand.svg`、`connection.js`、`connection-guide.json`、`update.js`、`navigation.js`、`studio.js`、`studio.css`、`agents.js`、`agents.css`、`manifest.webmanifest`、`service-worker.js`，以及 `assets/icons/`。以所選上游版本的這些檔案和功能為基準，保留版面、顏色、圖示、文字、導覽、手機選單及全部既有操作。安裝本身不授權另做簡化版、刪入口或重新設計 UI。

原生 Python 服務透過 `library --data ...` 或 `company/Dockerfile` 提供這套介面。`python blueprint.py`、`gui`、`serve` 及 `dist/index.html` 是舊版離線資料包工具，不能用來代替公司工作台。截圖、Pages 示範或只存瀏覽器的樣板亦不能作為正式安裝交付。

選 Sites 時先遵循[雲端指南的 Sites 路線](INSTALL_CLOUD.md)：平台適配以後台、登入及儲存為主，保留原版前端並逐項驗收。**目前公開倉庫提供 Python 原生部署檔，未包含可直接部署的 Sites 後台適配版本**；AI 必須說明並完成實際適配，或由使用者選擇現成原生部署，不能宣稱已有一鍵 Sites 安裝。普通聊天無法代做移植時，應將完整交接內容交給有實作工具的 AI。

## 中途停下或換對話

AI 在公開程式目錄以外的私人位置，維護 `INSTALL_PROGRESS.md`。已有記錄就讀取並驗證後接續；沒有記錄先檢查現存服務與資料，不能直接重建。

```text
模式：本機／雲端
任務：全新安裝／更新原站／另行資料搬遷
本次目標及保護範圍：新服務與私人資料位置；如有保留舊站，記錄其識別並標明不改動
目前步驟：所選指南的 L 或 C 步驟編號
程式來源及版本：實際 repo、分支、commit；本機絕對路徑
私人設定與資料位置：實際目錄／服務／永久磁碟或資料庫識別
Codex 環境：未使用／已準備／已發佈
部署方式：待選／本機／Render／Railway／自己的主機／Sites
正式服務或 Site：已有識別、實際網址；未有則寫「待建立」
已驗證：檢查項目、結果及日期
工作台：未啟動／待驗證／已可用
AI 連接：未設定／需使用者授權／已實際保存及讀回
下一步：一個明確動作；需要使用者完成的操作
日後啟動、停止、備份及更新方法：已核對的指令或平台入口
```

這是 AI 維護的交接記錄，不是現有程式自動驗證的結果。`setup` 指令只會產生 `company-profile.json`、`setup.json`、`deployment.env.example` 及 `START_HERE.md`；不會建立帳戶、網站或自動完成部署。重跑時已有自訂或不同設定會被保護，請接續原計劃，不覆寫私人資料。記錄中不放密碼、token、完整聊天或無關公司內容。

換對話可貼：

如果新對話不能讀取上一個環境的私人檔案，由原 AI 提供不含秘密的交接摘要，包含已選模式、實際倉庫及版本、已有網站識別與網址、目前步驟及下一個動作，讓使用者一併貼上。不要假設新對話自動取得舊環境檔案或全部聊天。

```text
請接續 Blueprint Studio Open Source 安裝。先讀我提供的私人 INSTALL_PROGRESS.md、
公開 docs/INSTALL.md 及 AGENTS.md，核對現存服務、資料與原版介面，再完成下一個未完成步驟。
沿用已有帳戶、工作台和資料，不重建網站或資料庫。每次需要我操作時，告訴我目前一步。
```

## 完整原版工作台驗收

兩條路線均用**真正啟動的工作台**完成下列驗收。新安裝以使用者同意的一筆簡短紀錄及無敏感資料的小檔案測試；不要擅自把示範公司或整段聊天灌入正式資料庫。

| 範圍 | 必須核對 |
| --- | --- |
| 入口及登入 | 使用者能打開實際地址並登入；未授權訪客無法讀公司資料。指定 ChatGPT 右側使用時，實際開啟同一個已部署網站 |
| 原版畫面 | 與所選上游版本比對該版本完整前端檔案及所需圖示；桌面導覽、原版首頁、卡片／清單及手機選單保持一致 |
| 全部入口 | 工作台、每日工作、待辦事項、文件庫、資料收藏、YouTube 學習、星號收藏、待整理、已封存、收藏集及公司設定 |
| 公司設定 | 名稱、行業、簡介及目標能讀取和修改，重開後仍保留 |
| 文件及收藏 | 上下載原檔、新增網站及 YouTube 連結、筆記、分類、標籤、收藏集、搜尋、篩選、排序、星號、封存及恢復 |
| 每日工作 | JSON 預覽及保存、讀回同一筆紀錄、修整內容、版本衝突保護、歷史版本、待辦勾選與狀態保存 |
| 資料交接 | 選取資料產生 AI 交接、匯出資料清單；清楚說明清單不包含附件，完整備份見 [LIBRARY.md](LIBRARY.md#更新與備份) |
| 持久儲存 | 刷新及重新登入查回；重啟本機服務或雲端重新部署後，同一筆紀錄、公司設定、附件及待辦進度仍在 |
| AI 連接 | 從內置 AI 接駁中心取得參數，呼叫 verify_connection 完成讀寫及待辦驗收；瀏覽器顯示相同紀錄 ID。新對話能讀取 connection_guide 規則，最後完成第一項真實工作；未通過記錄確切卡點 |

原生版目前的自動分類是本機規則；網址收藏不會自動抓取全文或 YouTube 字幕，亦不會自動讀取各家 AI 所有聊天。完整安裝是保留已有能力，不能宣稱未實作的功能。[功能及 API 說明](LIBRARY.md) · [每日工作與 AI 連接](DAILY_WORK.md)

若正式網址受工具網絡或登入限制，先完成可執行檢查，再請使用者在同一正式網址完成缺少的一步，記錄「待使用者驗證」。本機測試成功、部署工具回報成功及插件已建立，各自只證明對應階段。

## V2.6 公司與 Agent 工作台驗收

先按 [V2.4 原有功能與限制](V2.4.md) 及 [公司 API](STUDIO_API.md) 核對五組側欄、收件匣、項目、客戶／報價／發票、角色保護、多分類靈感及主題，再按 [Agent 規格](AGENT_CONTRACT.md)核對 Agent 工作台。V2.6 原生資料庫使用 **schema 6**，MCP 提供 **40 個共通工具、原生及 Sites 原生接駁共 42 個工具**；兩個額外工具只供擁有人維護備份。既有資料升級前完成備份與還原演練，追加 Agent 資料表並保留原紀錄、ID、登入、附件及設定。

需要接入 Agent 時，審核獨立倉庫的固定 commit 及 manifest，再登記並連接接口。驗證從工作台建立工作、目前 AI 對話讀取指定資料、保存真實結果及讀回同一 ID。設定衝突、未連接及失敗要清楚顯示；不會因加入套件而自動啟動 Codex。舊專員空殼、外部服務等待狀態及 Agent 的實際工作結果分開驗收。Sites 需完成同一正式後台的公司與 Agent API 適配，UI 包不能代替；本機測試也不代表正式 Sites 已通過驗收。

## 完成後交付

AI 提供一張簡短使用卡，並保存到私人進度記錄：

- **打開工作台：** 已核對的實際網址；本機附每次重新啟動的方法。
- **資料位置：** 真實私人目錄或雲端儲存，備份方式及更新時要保留的項目。
- **原版功能：** 已完成驗收項目；如有未通過，列出具體功能，不宣稱完整安裝完成。
- **AI 保存：** 已實測接通，或清楚列出尚缺的授權／連接步驟。
- **下次使用：** 開啟入口、說「今日收工」、修改工作紀錄的方法。

「工作台已可用」須有真實登入、原版功能及保存驗證；「AI 已接通」須有真實保存與讀回。完成 Codex 環境設定或產生計劃後，繼續所選安裝路線，直到交付上述結果。
