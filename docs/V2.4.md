# V2.4：把工作放在合適的位置

V2.4 保留原版標誌、白色與淺灰色、淡方格、無框文字，以及最多三頁的自由排版。新增五組側欄和可以保存、搜尋、修改、封存及讀回的公司工作內容。介面使用清楚的標準書面語。

本頁對照本次十頁《介面》規格。**原生本機及原生雲端版已實作下列資料功能；AI 專員依規格先提供未接入的設定空間。** 外部服務與 Sites 移植的界線列在頁末，不能算作已完成接駁。

## 每一列怎樣使用

| 位置 | 右側內容與可用操作 |
| --- | --- |
| 工作項目 → 今日總覽 | 沿用可移動版面；選擇最多三個今日焦點；查看每日工作、舊待辦、新待辦和公司提醒。專員數據只計正式匯入的真實對話，沒有紀錄時說明尚無資料。 |
| 收件匣 | 每項都有來源、狀態和內容。新收藏、指令及結果會入匣；可歸入項目、轉待辦、交給 AI、封存及還原。重複轉待辦沿用同一筆。 |
| 指揮中樞 | 保存指令、任務拆解、選定來源、結果和歷史。把交接內容貼給已連接的 AI，AI 使用真正工具完成工作；結果回到收件匣，外發或付款內容留作待確認草稿。 |
| 項目進度 | 規劃、開發、測試、上線、完成；百分比、負責人、到期日和可勾選里程碑；連結文件、對話、靈感及上線後負責的專員。 |
| 文件與成果 | 原有文件上下載、搜尋和整理保留；報告與交付物分頁保存 AI 結果及財務月報，可連到項目。 |
| AI 專員 → 按需選擇專員 | 新安裝不預先建立空白專員；管理員可明確選擇網站客服、WhatsApp、電郵或宣傳影片預設。既有專員、歷史和連結保留，封存後不會在啟動時重新建立。各有總覽、設定、對話、測試、數據；未接入不能標為上線。 |
| 從範本新增 | 預約、社交貼文、報價、知識問答、會議紀錄五款，只帶入角色和規則。 |
| 雲端與外部接入 | 模型、連接器／MCP、技能、渠道、用量五個分頁；登記服務、開關、伺服器憑證名稱及月上限。記錄用量後計入公司成本，達上限時工作台暫停並通知收件匣。 |
| 公司 → 潛在客戶 | 公司、公開來源、聯絡人、需要、規模及跟進紀錄；建立報價草稿時沿用聯絡資料。 |
| 報價與合約 | 項目、數量、單價、貨幣、有效期、條款；草稿 → 待確認 → 已確認 → 自行發送 → 已簽署 → 發票。十進位計價。確認後不能直接改內容，未發送可退回草稿。可下載 HTML，不會代發或代簽。 |
| 現有客戶 | 公司與聯絡資料，連結項目、合約及對話；簽署報價建立發票時自動建立相關客戶檔案。 |
| 反饋與客訴 | 新收到、處理中、已解決；來源、客戶、負責人、處理方法和解決時間。未解決項目出現在提醒內。 |
| 團隊與權限 | 管理員管理成員、人事備註、工時及登入，停用帳戶；只有老闆可以管理其他管理員。原老闆登入不變。 |
| 供應商與合作夥伴 | 聯絡資料、合作內容、付款條款及合約／項目關聯。 |
| 公司營收與發票 | 發票、已收、未收款項及月份；保存真實收款，不可超額。按貨幣計算及產生月報，不虛構匯率。封存不抹去帳目。 |
| 雲端與 AI 成本 | 日期、服務、接入、專員及費用分類；用量使用穩定來源識別，重試不重複記帳。 |
| 靈感庫 | 全部、網站、組件、AI、品牌、商業模式、學習；同一收藏可多分類。保存原始網址、日期、筆記、標籤、實際摘要與來源、上載的截圖；連結項目／專員／主題、轉待辦。相似推薦明示為標籤及文字比較。 |
| 自訂主題 | 沿用舊收藏集 ID 和內容，新增圖示、顏色及說明；引用項目、文件、靈感及對話，不複製資料。側欄前五個主題可拖動排序，其餘在全部主題。AI 交接只取本主題資料。 |

公司內的客戶／營運／財務只是分組文字。財務、人事及接入由伺服器檢查角色；搜尋、歷史、下載、舊文件路徑及 AI 工具均受保護，不只是隱藏側欄。

## 固定工具與個人設定

- 上方：原版標誌、公司入口、全域搜尋（⌘／Ctrl K）、指揮中樞（⌘／Ctrl J）、新增及釘選。沒釘選時不留空區塊。
- 公司入口保存已有工作台網址，各自登入和儲存；不是把多家公司混進同一資料庫。
- 下方：已封存、AI 接駁中心、說明、偏好、帳戶；封存內容可還原。
- 預設展開工作項目與 AI 專員；各帳戶保存展開狀態、窄側欄、提醒、隱藏主列與焦點。進入頁面展開所屬主列。
- 只為收件匣、待跟進反饋、待確認報價顯示數字；專員用狀態點。窄欄有名稱提示，手機有抽屜及底部指令按鈕。
- 舊每日工作、待辦、文件、收藏、YouTube、星號、待整理、封存和收藏集有對應入口。`?view=workdays`、`#/files`、`#/collection/ID` 會轉到新位置。
- 原排版按瀏覽器保存，新側欄偏好按帳戶保存；輸入、開表單、調整排版期間不刷新覆寫草稿。

## AI 真正怎樣寫入

先完成 [AI 接駁](CONNECT.md)。新增指令代表「已保存，等待 AI」，不代表背景模型已開始工作。

已連接的 AI 先讀 `blueprint_studio_state`，再讀指令和 `blueprint_studio_context` 的選定資料，保存拆解、使用實際工具工作，再以 `complete_command` 寫入結果及來源。結果回到收件匣，AI 讀回同一 ID。普通討論不自動保存；使用者要求保存或整理才執行。

30 個 MCP 工具供 Codex、Claude、Gemini 或其他相容客戶端使用；權限取決於登入帳戶，介面打開不等於工具已載入。

| 功能 | 實際狀態與下一步 |
| --- | --- |
| 專員自動回覆、影片、模型切換、渠道收信 | 依規格有設定、測試及工具入口，未附常駐模型／渠道執行器。需選供應商、伺服器秘密並實作執行器才可對外運行。 |
| 網址截圖、讀全文、AI 分類／摘要 | 保存網址只保留收藏、收件匣及靈感，不自動建立擷取指令。按「要求擷取與整理」才準備指定靈感的指令；重試沿用已有指令，舊有待處理工作不會被刪除。已連接 AI 要使用真實瀏覽工具，上載圖片並寫回摘要和來源。未附伺服器瀏覽器／背景模型，不能只貼網址就宣稱已擷取。 |
