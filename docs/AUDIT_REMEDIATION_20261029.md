## 更新與發布保留條件

- 正式候選以固定乾淨提交及最終下載網址建立；驗收同一 ZIP 後才具備發布資格。
- 渠道提升保留元件封套與產物；發布工作只取回已驗收產物，不重建或覆寫版本。
- 本批完成來源與合成測試，網上 Pages／Releases 設定及工作室更新屬之後的獨立階段。
- 更新前重新核對現有程式，發現客製修改先阻擋；資料、附件、設定、兩帳戶各自版面與既有草稿保護分開驗收。
- `feedback/` 是合成來源回歸契約，保留；正式發布仍逐檔核對公開內容。
- 舊後台的版面遷移驗收使用獨立瀏覽器情境；原帳戶未完成的保存、衝突及草稿不能為了測試而清除。
- UTF-8 產品／下載檔案使用明確編碼；Windows CLI 協定測試仍以原 locale 重現，不以全域旗標掩蓋問題。
