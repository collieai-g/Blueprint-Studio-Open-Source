# V2.2：由安裝帶到 AI 與工作台真正配合

工作台新增 **AI 接駁中心**。選擇客戶端及原生／Sites 路線，複製一段指令，由 AI 帶你完成設定、登入／授權、真實寫入及讀回，再開始第一項工作。

- 21 個 MCP 工具，新增共用接駁／工作規則及真實讀寫驗收。
- 右側核對同一筆測試紀錄，顯示來源、ID 與時間。失敗不報完成，換 AI 分開驗證。
- 內置工具載入、登入、網絡、版本、錯誤後台及畫面同步的接續指令。
- 保留原版 V2 介面及資料，沿用 schema 4，不重建資料庫。

下載 **installer.zip**，把包交給 AI，請它讀取 **INSTALL_AI.txt**。
已有工作台依 docs/UPGRADE.md 先備份，部署到同一服務，再由接駁中心完成驗收。
workbench.zip 供安裝 AI 更新已有相容網站的介面與 MCP 適配器，不能單獨當作完整後台。

Sites 仍須完成平台後台適配；平台登入、對話工具選用及網絡政策按該平台完成，包內已包含引導和卡點處理。

驗證：163 個 Python 測試、Node 測試、官方 MCP 新舊協定、真實瀏覽器與工具讀寫、Sites API 本機適配，以及 V1/1.5 舊資料保留檢查。未代每位使用者部署私人網站或完成客戶端帳戶授權。
