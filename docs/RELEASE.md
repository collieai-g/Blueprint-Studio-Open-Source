# V2.7.3：集中設定入口，讓側欄更簡潔

側欄底部只保留「設定」。使用說明、帳戶資料及 AI／MCP 接駁放在設定內，需要時再開啟。

- 「總覽、工作、AI、資料」四個主要入口保持不變，原有總覽卡片及瀏覽器排版偏好繼續沿用。
- 「已封存」移到「資料」區域，可查看及還原原有紀錄。
- 偏好、公司資料、更新助手及資料匯出仍可從設定使用。接駁中心保留真正的工具驗收，沒有另行啟動模型或背景服務。
- 介面更新包補齊[使用指南](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.7.3/docs/USER_GUIDE.md)引用的介面重繪圖片，與完整安裝包一致。圖片標示為重繪及示範內容，不作為實際保存或部署證據。

本版整理介面與導覽，沿用 schema 6、既有 API、來源權限及 MCP 工具合約，不新增資料遷移。日常保存工作、文件與待辦仍使用原有工作台。

首次安裝使用完整 installer.zip；workbench.zip 只包含需整合到相容後台的介面與說明。更新既有工作台時，沿用原網址、登入、資料及附件，先核對可還原備份。GitHub 發布不會自動部署私人服務。
