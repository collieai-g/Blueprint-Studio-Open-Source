# V2.3：自由排版，保持簡潔

工作台的標題、副標題和日期現在是可移動的無框文字，文件庫等內容仍以卡片顯示。所有項目的邊緣都會貼齊背景方格；平時只顯示內容，按「調整排版」才顯示工具。介面使用簡短、清楚的標準書面語。

- 短文字可設為兩格或四格；支援拖動、調整大小、方向鍵和觸控。
- 提供整齊排列、工作優先、簡潔排列三款起始排版。
- 底部提示增加一頁，由使用者按下按鈕確認，最多三頁。
- 沿用舊瀏覽器排版儲存鍵，首次保存前備份舊值。手機查看不覆寫桌面排版。
- 保留原版 logo、AI 接駁中心、21 個通用 MCP 工具、登入、文件、收藏、工作、待辦及歷史。資料庫仍為 schema 4，沒有新增資料遷移。

下載 `installer.zip`，把包內 `INSTALL_AI.txt` 交給有安裝工具的 AI。已有工作台按 `docs/UPGRADE.md` 備份並更新同一服務；Sites 可用 `workbench.zip` 整合到原網站，保留登入、資料庫、附件和工具。GitHub 發佈不會自動升級私人網站。

排版使用方式見 `docs/LAYOUT.md`。自動化與真實瀏覽器驗證見 `VALIDATION.md`。
