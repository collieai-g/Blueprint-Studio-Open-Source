# V2.4：五組導覽與公司工作流程

沿用原版標誌、白色淡方格、無框文字及最多三頁的自由排版，新增工作項目、AI 專員、公司、靈感庫和自訂主題。

- 收件匣、指揮中樞、項目／里程碑、文件成果，以及客戶 → 報價 → 已簽署 → 發票 → 收款流程。
- 反饋、供應商、人員與角色、按貨幣的營收成本月報；財務及人事由後台檢查權限。
- 多分類靈感、引用原資料的主題、釘選、全域搜尋、窄側欄、手機導覽與偏好。
- 四位未接入 AI 專員、七部分設定、五款範本、真實測試／對話紀錄、接入登記與用量提醒。
- 30 個 MCP 工具，讓不同 AI 客戶端讀寫同一後台；外發與收費仍先人工確認，不冒充已執行。
- 原生資料庫新增 schema 5 表，舊資料及登入保留。升級前完整備份；回復 V2.3 須用升級前資料快照。

**本版完成原生本機／雲端的資料流程。** 專員自動回覆、影片、網址截圖／摘要仍需外部工具及執行服務；瀏覽器擷取擴充套件尚未提供。Sites 完整新後台需在原網站適配，不能只更換 UI 包。逐項範圍及限制見 [docs/V2.4.md](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.4.0/docs/V2.4.md)。

下載 installer.zip，把 INSTALL_AI.txt 交給有安裝工具的 AI；已有工作台按 [docs/UPGRADE.md](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.4.0/docs/UPGRADE.md) 更新同一服務。workbench.zip 是前端及適配規格包，要求完整 V2.4 API，不是獨立後台。GitHub 發佈不會自動改動已安裝私人網站。

驗證紀錄見 [VALIDATION.md](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.4.0/VALIDATION.md)。
