# V2.7.2：左側 Codex，右側藍圖，一起管理公司

你在左側向 Codex 說明目標，Codex 使用 Skill 和真正可用的工具處理工作；右側藍圖讓你準備素材、管理待辦與文件、查看並保存成果。

- 重新設計中英文首頁，以左右並排示意圖說明產品的主要用途與分工。
- 新增[使用指南](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.7.2/docs/USER_GUIDE.md)：從開啟兩個工作區，到管理待辦、收藏、工作紀錄及個人化影片。
- 工作室總覽加入左右協作指引與可用的工作入口，保留原有可調整卡片及瀏覽器排版偏好。
- [完整協作流程](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.7.2/docs/LEFT_RIGHT_WORKFLOW.md)及[影片 Skill 範本](https://github.com/collieai-g/Blueprint-Studio-Open-Source/blob/v2.7.2/templates/skills/personal-video/README.md)隨安裝包與介面更新包提供。

左右示意是使用說明。實際 Codex 對話由客戶端提供，網站不會嵌入 Codex 或自動取得對話內容。Codex 客戶端具備並獲授權使用同一登入分頁的控制工具時，可操作畫面保存並重新查看；MCP 保留為另一條路線。Skill 匯出不會自動安裝外掛、啟動 AI 或製作影片。

本版沿用 schema 6、四個主要入口及既有工具合約。公司資料、附件、登入與保存權限保持相容。日常新增待辦、保存文件及更新工作紀錄不需要 Git 提交或重新部署。

首次安裝使用完整 installer.zip；workbench.zip 需整合到現有相容後台。既有工作台請按更新入口，保留原網址、資料及可還原備份；GitHub 發布不會自動部署你的服務。
