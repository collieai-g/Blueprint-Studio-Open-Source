# 從最簡總覽開始，自己選擇內容

[返回首頁](../README.md) · [使用指南](USER_GUIDE.md) · [保留資料更新](UPGRADE.md)

**V2.7.4 的總覽預設只顯示「總覽」標題及「調整排版」。** 沒有預設統計卡片、左右協作教學或 AI 連接卡片。公司資料仍可從「工作」及「資料」使用；是否把卡片放到總覽，由你決定。

## 加入需要的內容

1. 按 **調整排版**，打開排版編輯器。
2. 在 **顯示的內容** 勾選需要的模組。標題保留；副標題、日期、文件庫、資料收藏、YouTube 學習、待整理、最近工作、待辦事項和最近更新皆可選擇。
3. 勾選後可拖動、調整大小或收合卡片；想改文字大小，可選兩格、四格或輸入寬高。
4. 不需要的模組取消勾選。隱藏只改變顯示，不刪除公司的資料，也不重設待辦或附件。
5. 按 **完成調整**，回到正常畫面。成功修改會保存到目前瀏覽器。

「整齊排列」、「工作優先」及「簡潔排列」只調整所選內容的排法，不會替你重新開啟隱藏模組。舊版的介紹文字與 AI 連接卡片不再是可顯示模組。

## 文字、卡片與空間

標題、副標題及日期是透明文字，沒有卡片底色；資料模組保留可操作的卡片。內容沿淡色方格對齊。進入編輯時才顯示邊界與調整工具；平時按實際可見內容收起空白高度。

用滑鼠拖動移動按鈕，或拉右下角調整大小。鍵盤可用 Tab 選取移動／大小控制後按方向鍵，每次一格；拖動中按 Esc 可取消。手機亦可使用觸控及工具列，單純縮窄視窗不覆寫桌面排版。

編輯時每頁高 48 格，需要更多位置才按 **增加一頁**，最多三頁。拖動不會自行加頁，也不會複製公司的資料。正常查看不固定佔滿所有空白頁高。

## 舊排版與備份

主儲存鍵仍為 `blueprint-workspace-v2`。V2.7.4 的 `layoutVersion: 4` 新增 `visible` 清單，預設為標題；舊有位置、大小、輸入模式和頁數繼續保留。只打開新版或縮窄視窗，不會改寫舊值。

第一次明確保存新版排版前，系統將原始舊值另存到 `blueprint-workspace-v2.7.3-backup`，已有該備份時不覆寫。更早版本的 `blueprint-workspace-v2.2-backup` 亦保留。舊模組起初隱藏，需要時在編輯器重新勾選，不表示資料或幾何位置已刪除。

排版屬於同一網站的目前瀏覽器，不會自動同步到另一部電腦；清除網站儲存會清除瀏覽器偏好。公司文件、工作、待辦、附件及歷史保存在原後台。排版備份不是完整公司資料備份，完整還原仍按[更新指南](UPGRADE.md)處理。

## 安裝與更新時核對

核對預設只有標題和排版按鈕、模組可加入及隱藏、文字無框、卡片貼格、拖動／方向鍵／取消、縮放／收合、三頁上限及手機可用。首次保存前後檢查舊值備份與重開保存；保留原工作資料、權限、ID 和附件。

AI 設定在左側按 [AI_CONNECT.md](../AI_CONNECT.md) 完成，總覽不提供接駁步驟。程式發佈與私人站部署分開；發佈 GitHub 包不會改動你目前的工作台。
