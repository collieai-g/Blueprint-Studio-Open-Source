# 把工作台排成你喜歡的樣子

[返回首頁](../README.md) · [保留資料升級](UPGRADE.md)

V2.3 使用同一套淡色方格。標題、說明、日期和內容卡片都能移動；每次移動或改變大小，都會貼齊方格。平時保持簡潔，只有調整時才顯示工具。

## 文字不用卡片包住

「工作台」、副標題、介紹和日期是透明的文字區塊，沒有底色、邊框或陰影。它們和內容卡片一樣可以移動。兩格或四格特別適合短標題和日期：

- **兩格：** 寬兩格、高一格；也可自行設定為寬一格、高兩格。
- **四格：** 寬兩格、高兩格。
- 長說明可以保留較大空間。縮得太小時會縮小字體或省略顯示，文字本身保留；滑鼠停在文字上可看完整內容。

文件庫、資料收藏、YouTube 學習、待整理、最近工作、待辦事項、AI 連接和最近更新則保留卡片外觀。內容卡片至少寬六格、高四格；最近更新至少高六格，讓按鈕和資料仍可使用。小型摘要卡會收起內文，按「查看」仍可開啟完整內容。其他卡片內的長內容可以捲動查看。

## 調整一次，以後繼續使用

1. 按工作台右上方的 **調整排版**。
2. 拖動項目的移動按鈕；拉右下角來改變大小。移到其他項目旁時，系統會找出不重疊的位置。
3. 小文字也可以從上方的 **調整項目** 選取，再按 **兩格**、**四格**，或輸入寬度與高度後按 **設定大小**。
4. 想先選一個起點，可選 **整齊排列**、**工作優先** 或 **簡潔排列**，再按 **套用排版**。之後仍可自由調整。
5. 按 **完成調整**，工具與文字邊界便會收起。每次成功調整都已保存。

不用滑鼠也可以操作：用 Tab 選取移動或大小按鈕，再按方向鍵，每次調整一格。拖動途中按 Esc 可取消該次調整。觸控螢幕也可拖動按鈕，或使用上方的大小及頁面選單。

空間不足的調整會保留原位置並顯示提示，不會藏起其他項目或自行加頁。手機會按螢幕重新排列；只是查看手機版，不會覆寫原有桌面排版。若在手機明確調整，則會保存當時的排版。

## 需要更多空間，再增加一頁

新工作台由一頁開始，每頁高 48 格。滑鼠移到版面底部，或用 Tab 選取底部，會看到 **需要更多空間嗎？**。按 **增加一頁** 才會向下增加；觸控裝置會直接顯示按鈕。

最多三頁。移動項目到下方不會自行加頁。新增頁面後，可在調整工具的 **移到頁面** 選擇第二或第三頁，也可以拖動到該頁；接近畫面邊緣時會捲動。每個項目都留在同一頁內，不跨越頁面分界。增加的是空白位置，不會重複你的資料。

## 排版和工作資料分開保存

排版保存在同一網站、同一瀏覽器，重新開啟後會保留。它不會自動同步到另一部電腦；清除網站資料也會清除排版。公司文件、收藏、工作、待辦及歷史仍在原後台，不受排版影響。

升級 V2.2 或更早版本時，系統會轉換舊六張卡片的位置，保留大小、收起狀態和輸入方式，必要時調整重疊。舊版很長的排版可能需要兩至三頁，最多三頁。首次保存新排版前會另存舊值，詳見 [升級與回復](UPGRADE.md)。

## 給安裝 AI 的驗收要求

沿用本版完整 HTML、CSS 和 JavaScript。不要另畫一套介面，也不要為無框標題加上卡片底色。保留所有既有導覽、資料操作、登入與 AI 連接。

驗收桌面及手機：文字無框、方格對齊、兩格／四格文字、拖動、方向鍵、取消拖動、收起、三款排版、明確加頁及三頁上限、重新開啟保留、舊排版備份，以及最近更新和文件／工作導覽仍可使用。安裝完成後以簡短的標準書面語帶使用者完成一次調整；不要只列出技術名詞。
