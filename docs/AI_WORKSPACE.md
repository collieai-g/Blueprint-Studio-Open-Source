# V2：在對話交代工作，在工作台查看成果

[返回首頁](../README.md) · [保留資料升級](UPGRADE.md) · [MCP 接駁指南](AI_CONNECTION.md)

日常新增工作、更新待辦、保存文件、加入收藏及整理公司報告，都透過既有工具保存資料，不修改 GitHub、不重新部署 Sites。公司與 Agent 的現有設定亦直接保存；排版偏好保存於目前瀏覽器。只有修改程式或升級版本時才走程式整合與部署，詳見[主要運作方式](OPERATING_MODEL.md)。

先按 [AI_CONNECTION.md](AI_CONNECTION.md) 接通實際讀寫工具，支援 Codex、Claude、Gemini 等相容 MCP 客戶端。

V2.4 已內置「AI 接駁中心」。每個新對話先讀 blueprint_connection_guide 取得工作規則；把此步驟及後台地址合併到客戶端支援的私人指引。初次接駁使用中心產生的參數呼叫 blueprint_verify_connection，讓右側獨立確認結果，見 [CONNECT.md](CONNECT.md)。

V2 預設收起重複的手動填表入口。你可以直接對已連接的 AI 說：

- 「將這份文件放進文件庫，按內容加入合適分類。」
- 「保存這個網站，放進設計參考收藏集。」
- 「將這段 YouTube 連結加入學習庫，記低我提供的重點。」
- 「幫我整理今日工作，保存成果、決定同下一步。」
- 「將這個待辦標記完成。」

AI 在原有授權範圍內判斷資料類型並寫入同一個工作台，不需要逐個欄位再問一次。缺少必要資料、目的不清楚或需要你登入時，才問具體缺少的一項。未提供的內容不能編造；沒有可用工具時要說明連接仍欠缺，不能假裝已保存。

## AI 使用既有資料接口

| 內容 | 原生後台操作 | 工作台位置 |
| --- | --- | --- |
| 文件 | `POST /api/files`，保留原檔；必要時由使用者用保留的上載按鍵選取 | 文件庫 |
| 網站、設計參考 | 查詢現有收藏後 `POST /api/items` 或版本化更新，重用收藏集 | 資料收藏 |
| YouTube 連結 | 同一收藏 API；提供真實 YouTube URL，來源類型由既有規則辨認 | YouTube 學習 |
| 成果、決定、參考、待辦 | `workday-save`／`workday-revise` 或 `/api/workdays`；沿用穩定來源識別 | 每日工作／待辦 |
| 完成待辦 | `PATCH /api/todos/{id}`，帶最新 `expected_version` | 待辦事項 |
| 公司資料 | `/api/company-profile`，保留未修改欄位並檢查版本 | 公司設定 |

操作前讀取相關既有資料，避免重複收藏、重複日報或覆寫較新修改。完成後讀回真實 ID，說明保存在哪個位置。Sites 使用該網站已部署的工具及認證，不能假設其支援原生 Basic 認證；具體欄位按實際工具 schema。

原生 API 的登入、寫入標頭及詳細格式見 [LIBRARY.md](LIBRARY.md#日後-agent-可使用的-api)。AI 只能使用目前可見、使用者提供或授權工具取得的內容；收藏網址不代表已讀取全文，YouTube 連結不代表已取得字幕。

## 工作台怎樣配合

- 可見頁面每約 10 秒讀取同一個後台，亦可按「重新整理」。這只是資料同步，不會自行讀取左側對話。
- 有開啟的編輯視窗、輸入焦點、選取資料或正在調整卡片時暫停同步，保留尚未保存的操作。
- 搜尋、上載檔案、下載、勾選待辦、必要修改保留。「備用操作」集中提供手動匯入、收藏及新增收藏集。
- 偏好設定可切回顯示手動入口；沒有連接 AI 的使用者仍可使用完整後台。
- 標題、說明和日期是可移動的無框文字，支援兩格／四格；內容卡片保留外觀。按「調整排版」可沿 24px 方格移動或改變大小，也可用方向鍵操作。底部可增加頁面，最多三頁。排列保存在目前瀏覽器，不會改動公司資料；見 [排版指南](LAYOUT.md)。
