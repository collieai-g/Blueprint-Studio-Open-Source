# 使用指南：左側指揮 Codex，右側管理公司

**你在原本的 Codex 介面指揮工作，在自己公司的藍圖工作台管理資料和成果。** 這裡的左右是兩個真正使用的介面，先完成一項小工作，再逐步整理公司的日常。

左右排列由客戶端或並排視窗提供。藍圖與現有 Codex 配合，不提供另一個內建模型或取代 Codex 的聊天介面。

## V2.8：每頁有自己的版面

左側 Codex 沿 [AI_CONNECT.md](../AI_CONNECT.md) 完成接駁、登入及測試；右側使用「總覽、工作、AI、資料」四個入口。項目、收件匣、待辦等次級入口放在最上方的橫向導覽，右上角 **操作** 集中搜尋、更新資料及加入內容。側欄不再有收窄選項，上方亦不重複顯示工作空間路徑。

每頁可按 **調整版面**，安排支援卡片的位置、大小、收合及顯示文字。卡片有尺寸上下限，文字修改只影響自己的顯示，不改寫正式資料；各頁配置分別保存在目前瀏覽器。手機查看不會覆寫桌面配置，正常填寫的內容不會當成拖動。

總覽預設只有標題，可在 **調整版面 → 顯示的內容** 加入資料模組；也可將工作或 AI 頁面支援的卡片加入總覽。卡片保留原紀錄引用，重新查看時按目前權限讀取，原資料變更後可按 **操作 → 更新資料** 核對；不能讀取時不繼續顯示舊內容。完整方法見[個人版面指南](LAYOUT.md)。

這份來源說明不代表任何既有私人或測試工作台已更新；客服 Agent 仍由獨立項目開發，這次介面調整不等於完成聯合接入驗收。

## V2.8：查看獨立服務的工作

已在原生後台註冊外部服務時，可在「工作 → 外部工作」查看它實際提交的紀錄、來源、同步時間及操作結果。沒有服務時不出現此入口；註冊本身也不代表服務正在運行或已通過接入驗收。設定與授權由左側的受控 API 管理，右側不新增接駁精靈。

選擇服務宣告的動作並按「保存指令」，只會先保存待處理要求。外部服務確認後才更新狀態；「結果不明」表示仍須查證，不能當作失敗而重發。按「更新外部紀錄」讀取新結果，填寫中的內容會保留，閒置不自動重載頁面。外部客服或其他專用操作頁仍在各服務的網站開啟。

V2.8 提供通用接駁介面，不內置 WhatsApp 或客服 AI。開發者接入、公司知識版本與權限設定見 [接入指南](INTEGRATION_GUIDE.md)。這份來源說明不表示你的現有工作台已部署新版。

## 這個工作台為誰而設

藍圖面向創業者和小型團隊，幫助公司持續管理任務、項目、文件及工作紀錄。沿用 Codex 已有的 AI 工作流程與工具能力，可以把開發資源集中在公司資料、管理流程和專業 Skill，減少重複開發通用 AI 控制層。

共用後台和介面可按業務需要修改。可重用 Skill 定義影片設計等專業方法；真正的推理和製作，由你指揮 Codex 配合已提供、已授權的工具完成，成果再存回藍圖。

## 把兩邊放在一起

1. 在平常使用的 Codex 軟件開啟對話。
2. 把屬於你公司的藍圖工作台開在右側瀏覽器，或放到旁邊的另一個視窗，完成登入。
3. 核對右側的公司名稱，確認這就是本次要保存資料的工作台。
4. 在左側交代一項工作，並指定可使用的材料和保存位置。

左右排列由客戶端或你自己的視窗安排提供。若尚未安裝工作台，先按[首次安裝指南](INSTALL.md)完成登入、持久儲存與備份驗收，再回到這裡。

### 先確認 Codex 可以怎樣幫你

可以在左側說：

> 請先確認你能否操作右側這個已登入的藍圖工作台。能操作時，使用正式畫面完成我指定的工作，保存後重新開啟同一筆紀錄核對；否則說明目前可以使用的保存方式。

| 目前具備的能力 | 怎樣配合 |
| --- | --- |
| 能控制同一個已登入工作台 | Codex 可點擊、填表和上載，沿用你在畫面上的權限。你不用另寫 API。 |
| 已接通藍圖 MCP／工具 | Codex 可透過已授權工具保存及讀回，右側查看同一份資料。MCP 是可選路徑。 |
| 只能對話或查看網頁 | 先整理文字、Skill 或成果檔案，再由你保存，或交給具備相應工具的客戶端。 |

**看得到網頁、能控制網頁、內容已保存，要分開確認。** 藍圖不會替 Codex 增加瀏覽器控制權；另一個測試瀏覽器也不等於你的登入分頁。無論用畫面或工具，藍圖後台都會處理登入、權限、版本及儲存。

## 第一項工作：把會議變成待辦

在右側「資料 → 文件」上載會議紀錄，或直接在左側提供這次要整理的內容。已有項目時沿用，不要再建一份相同項目。

在左側說：

> 只使用我這次指定的會議紀錄，整理已確認的決定，列出三項可跟進的待辦，放到這個項目。保留原本已完成的待辦，保存後重新開啟相同紀錄，告訴我保存在哪裡。

你在右側核對：

- 「工作 → 項目」是否顯示正確項目及進度。
- 「工作 → 待辦」是否有對應內容，原有完成狀態是否保留。
- 重新開啟相同紀錄後，文字和來源是否正確。

若 Codex 只交付了整理好的文字，這份文字仍是對話成果；尚未存入藍圖時，不能當作工作台已保存。

## 每天可以怎樣使用

| 想完成的事 | 在左側指揮 Codex | 在右側查看 |
| --- | --- | --- |
| 安排今天的工作 | 「根據我指定的待辦，整理今天最重要的三件事。」 | 工作中的待辦；需要時把工作／待辦卡片加入總覽 |
| 跟進一個項目 | 「整理這個項目的最新進度，更新接下來的工作。」 | 工作 → 項目；核對原有項目及待辦 |
| 保存文件及參考 | 「保存這份報告和這個參考網址，整理到相關主題。」 | 資料 → 文件／收藏／主題 |
| 整理一天的成果 | 「今日收工，保存今天確認的成果、決定和未完成工作。」 | 工作 → 工作紀錄，再查看對應待辦 |
| 準備專業工作 | 「按這些品牌材料，幫我準備影片設計 Skill 和製作要求。」 | AI → Skill 與交接 |
| 找回舊資料 | 「在我有權使用的資料中，找回這個項目的報告。」 | 資料的搜尋、主題或釘選 |

右側只有「總覽、工作、AI、資料」四個主要入口，細分內容在最上方的橫向導覽。文件可用右上角「操作 → 加入檔案」上載，參考網址用「操作 → 收藏連結」，搜尋及更新資料亦在同一選單。每頁可按「調整版面」保存自己的配置；總覽可加入資料模組及工作／AI 紀錄卡片。

**日常保存不需要改 GitHub 或重新部署。** 新增報告、待辦、文件、收藏及既有設定，使用現成操作保存即可。修改程式、按鈕或新增尚未支援的功能，才是軟件更新。

## 左下角只保留設定

日常工作使用「總覽、工作、AI、資料」。偶爾才用的管理及說明集中在左下角「設定」，不再各自佔用側欄。

| 原有入口 | 用途 | 現在的位置 |
| --- | --- | --- |
| 偏好設定 | 公司資料、顯示方式、排序、更新及匯出 | 設定 |
| 帳戶 | 核對登入身分、角色和版本；有權限時管理團隊登入 | 設定 → 帳戶資料 |
| 使用說明 | 查閱操作方法和完整手冊 | 設定 → 使用說明 |
| AI 接駁 | 核對實際客戶端、登入、工具及保存驗收 | 左側 Codex 讀 AI_CONNECT.md |
| 已封存 | 查看及還原收起的資料 | 資料 → 已封存 |

Codex 已有操作同一個已登入工作台的能力時，可以直接使用畫面，毋須另行設定 MCP。需要 MCP 時，也在左側按 AI_CONNECT.md 設定；右側不切換模型、不授予瀏覽器控制。帳戶、資料權限、保存及還原功能繼續由原後台處理。

## 製作一段個人化影片

先把品牌圖片、產品資料和這次允許使用的參考材料放到藍圖，再開啟「AI → Skill 與交接」。

1. 選「個人化影片設計」，填寫工作名稱、目標、受眾、片長、風格及完成條件。
2. 勾選本次來源。來源編號和名稱只是交接資訊，原始附件仍需經獲授權方式讀取。
3. 需要更合適的專業步驟時，請左側 Codex 起草，再填進「可重用的專業規則」。
4. 按「複製給 Codex」交接本次要求；可另行下載 `SKILL.md` 及私人交接單，或按「保存交接單到報告」。
5. 在左側要求 Codex 按 Skill 製作腳本、分鏡，再使用目前真正可用的影片或剪輯工具完成製作。
6. 把實際成品、製作文件和來源保存到指定位置，再重新開啟核對。

例如：

> 用這次選定的產品照片，製作 30 秒直式短片，沿用品牌的沉穩風格和繁體中文字幕。先核對你真正可用的影片工具，再完成腳本、分鏡及能實際製作的部分。把成品和製作文件保存到這個項目，讀回核對。

| 檔案或狀態 | 代表甚麼 |
| --- | --- |
| 可重用 `SKILL.md` | 專業流程和檢查規則，供支援的客戶端載入 |
| 私人交接單 | 這次目標、風格、限制及選定來源 |
| 交接單已保存到報告 | 要求已存入藍圖，製作工作尚未因此開始 |
| 真實影片成品 | 製作工具完成後可開啟的檔案或有效成品位置 |

下載 Skill 不會自動安裝外掛，也不會喚起 Codex。Skill 提供方法，影片工具提供實際製作能力；沒有影片工具時，可以先完成腳本及分鏡，影片保持待完成。這樣可重用你的風格和流程，而不用為每種影片另建一個 AI 服務。

## 每次保存後，看回同一筆結果

1. 核對保存的是正確公司、項目及位置。
2. 使用原來的紀錄編號或「查看已保存」入口重新開啟，確認文字和待辦。
3. 有附件時，確認實際檔案可以開啟；來源及連結也應對應這次材料。

工作台內保存後會更新相應內容。外部工具保存後，按右側「更新資料」讀取最新內容；閒置、切回視窗或還原瀏覽器歷史，不會自動重建畫面。

保存結果不明時，先找回原紀錄，不重複新增。若顯示版本衝突，保留草稿，讀取最新內容後再整合，不覆蓋別人的新修改。

## 公司資料與權限怎樣處理

你在右側登入哪個帳戶，畫面操作就沿用該帳戶權限。AI 工具也須經正式授權，不能自行指定管理員身分。

| 身分 | 主要責任 |
| --- | --- |
| 擁有人 | 管理工作台、重要權限及備份 |
| 管理員 | 處理獲准的公司資料及管理設定 |
| 成員 | 跟進獲准的工作與資料；財務及人事等受後台規則保護 |

只交給 Codex 這次明確選定或你提供的材料。一般聊天不會整段自動存入，藍圖不會自行讀取其他平台的私人對話。公開 GitHub 保存程式及範本，公司文件、私人偏好、憑證和備份放在私人位置。

## 需要進一步設定時

- 尚未有工作台：按[完整安裝指南](INSTALL.md)，由有相應工具的 AI 帶領完成。
- 要設定 AI：在左側讀 [AI_CONNECT.md](../AI_CONNECT.md)；選用 MCP 時，由實際客戶端產生本次測試參數，按[技術指南](AI_CONNECTION.md)及[驗收流程](CONNECT.md)完成真正保存和讀回。畫面操作不冒充 MCP 接駁測試。
- 需要固定版本和工作狀態：查看可選的[Agent 工作規格](AGENT_CONTRACT.md)。一般 Skill 不必先登記 Agent。
- 想升級程式：按[更新路線](UPDATE_ROUTE.md)，先核對完整備份，再更新原有服務及資料。

你主要做的是交代目標、選定材料和核對成果。專業推理由目前 Codex 對話處理，藍圖讓公司資料可以找回、跟進和持續使用。
