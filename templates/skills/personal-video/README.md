# 個人化影片 Skill 範本

這個範本把影片設計的專業方法交給目前 Codex 或相容 AI 客戶端，配合藍圖的資料與成果介面。使用者可以先做 Skill，沿用已有的影片工具，無須為每種影片另外建立模型服務。

入口是 [SKILL.md](SKILL.md)。它包含材料核對、腳本、分鏡、製作、成品檢查及回存流程；不包含影片模型、帳戶、憑證、公司材料或已運行的影片服務。

## 使用方式

1. 把這份範本複製到所選客戶端支援的 Skill 來源位置，保留穩定名稱，按需要修改工作方法。公司專用版本和偏好放在私人位置。
2. 依該客戶端的正式方式安裝或載入，核對目前對話確實讀得到這份 Skill。不同客戶端的安裝目錄與流程各自處理；下載檔案本身不代表安裝完成。
3. 在藍圖上載材料並選定這次可使用的來源，準備單次工作說明，再向左側 Codex 提出製作要求。
4. Codex 檢查實際可用的影片、圖片、剪輯及瀏覽器工具，使用已授權能力完成工作，回存真實成果並重新查看同一筆紀錄。

沒有影片工具時，可先完成腳本、分鏡、字幕和製作指令；成片仍是待完成項目。這份範本不會自動安裝外掛、啟動 Codex、連接模型或對外發布影片。

## 單次工作說明

可沿用以下欄位。未提供的內容保持空白，由目前對話按實際需要補充。

```text
工作名稱：
工作台／項目：
影片目標與對象：
片長、比例及語言：
品牌語氣、字幕及風格偏好：
必須保留的產品事實：
本次選定來源與版本：
預期交付物及回存位置：
目前已授權的工具與製作範圍：
```

工作說明連同附件屬於私人工作資料，不提交這個公開範本。來源編號不會把附件內容一併匯出；要由目前客戶端經獲授權的畫面或工具取得。

## 驗收

確認目前對話讀到正確 Skill，實際製作工具可用，成果可開啟，以及藍圖按相同編號讀回一致內容。若採用畫面控制，還需驗證工具控制的是正確已登入工作台；若採用現有 Agent 工作，保留其來源、版本及狀態檢查。

完整分工見[左右協作流程](../../../docs/LEFT_RIGHT_WORKFLOW.md)及[主要運作方式](../../../docs/OPERATING_MODEL.md)。
